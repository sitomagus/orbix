## 📌 Sobre o projeto

O **Orbix** é uma rede social desenvolvida para o projeto final da unidade curricular **Projeto de Desenvolvimento II (ADS6N26-1)** do curso de **Análise e Desenvolvimento de Sistemas**.

A proposta busca criar uma alternativa às redes sociais atuais, priorizando interações mais significativas, menor estímulo de engajamento e uma experiência visual inspirada na nostalgia da **Web 2.0**, **Frutiger Aero** e **Windows 7**.

---

## ✨ Funcionalidades

- Cadastro e login;
- Publicações, curtidas e comentários;
- Sistema de amizade;
- Chat privado;
- Feed limitado aos amigos;
- Interface responsiva.
